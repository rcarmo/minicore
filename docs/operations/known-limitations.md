# Known limitations and deployment boundaries

Minicore runs a bounded, synthetic IPv4 network. These limits apply to the [simulator contract](../../SPEC.md).

- **Local/private scope.** Compose publishes only `127.0.0.1:19000`. Private development allows anonymous Operator access and does not provide per-user accountability. Invalid or revoked credentials fail closed. Remote callers require TLS, source filtering and authenticated deployment. The repository does not configure remote ingress.
- **Synthetic topology.** The lab has a fixed eight-node, nine-link topology and two endpoint LAN prefixes. There is no runtime topology editor and no production data. Cooperative router-root and host-root administrators can change namespace controls; this is not hostile-tenant containment.
- **FRR variant.** FRR 10.4.1 source is checksum pinned and changes only four SYS_ADMIN declarations for plain-IP operation. There are no privileged containers and no SYS_ADMIN grant. Namespace and VRF operations that need that capability are unsupported. IPv6 forwarding is disabled. No IPv6 routing acceptance is claimed.
- **Routing evidence.** Observations are non-atomic and stale after 30 seconds. Graph and table protocol facts keep endpoint disagreement. Physical link health is not inferred from container state. Pre-policy received and import-policy evidence is `not_collected`. Exports do not prove peer receipt or acceptance. Comparison retains two complete fresh samples in one prefix, generation and declared scope. It is not a historical telemetry database.
- **Node evidence.** Configuration browsing is a bounded, redacted declared baseline, not live running configuration. Logs retain a rolling 15-minute, 500-row, 60-KiB container snapshot, not complete history. Empty, unavailable, stale, malformed and failed collections stay distinct.
- **Fault and audit semantics.** There are three legacy scenarios plus inventory-derived node or link stop and fixed random corruptions, with one active mutation at a time and fixed commands. Idempotency and audit retain 128 records. Retries after eviction are not guaranteed safe. Local audit is bounded operational evidence, not an external archive or tamper-proof record. A TCP disconnect does not roll back a mutation. Reconcile by key or state, then reset. Disk loss remains an explicit recovery error.
- **Browser and performance.** The full graph was tested on headless Chromium with SwiftShader. Firefox and WebKit evidence and fallback contracts passed, but native GPU graph rendering there is not certified. A local Chromium/SwiftShader run at 1440×1000 measured a 150 ms frame p95 with occasional software-rendering stalls. There is no universal 60 fps or tablet hardware performance guarantee.
- **Recovery load.** Whole-node restart checks briefly exceeded the management container's three-second Docker health-check timeout during concurrent SSH collection. Health recovered after the workload settled. The container is limited to one CPU and 256 MiB; readiness probes can time out under resource contention.
- **Build reproducibility.** Digest bases, exact added APK versions, FRR source checksum, and Python and Bun locks are checked. Pinned upstream artifacts still need network availability. There is no offline mirror and no bit-identical build promise. SBOM and licence inventory are not a vulnerability scan or legal certification.
- **Host collector lifecycle.** This is an explicit opt-in user-systemd service and is not auto-enabled. Abrupt termination can leave `runtime/log-collector.lock`. Verify that no collector process exists before you remove the empty lock and restart. Never bypass a live lock. Presence goes stale after 45 seconds; logs after 15 seconds.
- **Filesystem operations.** Live reads and controller writes use bounded off-loop workers. Running filesystem calls cannot be forcibly cancelled; shutdown and cancellation drain them. Queued jobs cancel before executor submission and immediately release admission. Shutdown rejects new work and drains admitted jobs even when cancelled. Topology reads stop after three generation conflicts: HTTP returns `409 generation_mismatch`, MCP returns a typed error, and SSE closes without publishing stale data. Credential redaction retains at most 128 token values or 64 KiB per process. Exhaustion disables log/configuration evidence without blocking credential revocation. Retired tokens must be removed from source evidence before restart because the redaction set is volatile.
- **Specification backlog.** Planned feature files remain design or future cases and are excluded from runnable current acceptance. They include advanced policy, topology and history, and remote deployment refinements. Not every planned scenario has been implemented.
- **Routing and IGMP observer.** The local deployment uses a 60-second volatile window, scoped kernel and drop counters, and bounded IGMP-only capture. It has no application inspection, packet files, exports, IGMP membership inference, IPv6 MLD or PIM, or fragmented packet reassembly. The [observer contract](../specs/routing-observer.md) gives exact limits and the [runbook](runbook.md) has service instructions.
