# Network workbench prototype

Preact + Three.js, entirely Bun-managed. `bun install --frozen-lockfile`, `bun run check`, `bun run test:browser`, `bun run test:bdd`. Production assets in `dist/` are copied into the Python image; no CDN is required. Complete expected topology renders before routers exist. Logs now support bounded real container messages, Follow/Pause, Latest/Older and loaded-page severity filtering. Configuration browses the declared per-node file tree read-only. Continuous UI routing evidence stays unknown until the SSH adapter is connected; separate real-lab tests prove current baseline routing. Node/link lists provide a WebGL fallback. Deterministic browser acceptance starts a disposable service at 127.0.0.1:19123. Opt-in live-log BDD uses MINICORE_URL (default http://127.0.0.1:19000).
